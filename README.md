# Restaurant Budget Planner

## Project Overview
Restaurant Budget Planner is a Java desktop application designed to help restaurants manage budgets, expenses, and revenue using an Oracle database.

## Technologies Used
- Java
- Java Swing
- JDBC
- Oracle Database
- Oracle JDBC Driver (`ojdbc11.jar`)

## User Roles
- **Manager:** Creates budget plans and reviews financial performance.
- **Accountant:** Records expenses and revenue.

## Main Modules
1. Authentication
2. Budget Management
3. Expense Management
4. Revenue Management
5. Financial Analysis
6. Reports

## Project Structure
- `AUTHENTICATION/` — User authentication
- `BUDGET/` — Budget management
- `EXPENSE/` — Expense management
- `REVENUE/` — Revenue management
- `FINANCIAL_ANALYSIS/` — Financial calculations
- `REPORT/` — Financial reports
- `GUI/` — Graphical user interface
- `DB/` — Database connectivity
- `database/` — SQL scripts
- `docs/` — Project documentation
- `lib/` — JDBC driver

## Database
The application uses Oracle Database and JDBC to store and retrieve restaurant financial records.

## How to Run
1. Install Java JDK 17 or a compatible version.
2. Install and configure Oracle Database.
3. Configure the Oracle database connection in the application.
4. Ensure the Oracle JDBC driver is available.
5. Compile and run the Java application using the project's configured commands.
